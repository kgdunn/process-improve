- **Browser app (factori.al): a workbook carries its study's settings.** A workbook downloaded from a study now
  holds the study's settings (its colour map, its decimal mark, its significance level), and a workbook read back
  puts them in force, as the study's link and file already did. A workbook with none opens with a new study's
  settings. The Python code shown names the study's colour map, `colorscale("lajolla")`, where the code draws one
  itself.
