- factori.al's run sheet and What if are one table, in Run. Over the names, the factors and the responses in groups, and under them a row of each factor's range and each response's goal in words. Once there are results, a row of pictures for each response and the What-if row sit over the runs in the same columns, with each response's prediction in its own column. A result that misses its goal has a dagger, and the best run so far is in bold. Learn links to the What-if row (#1504).
