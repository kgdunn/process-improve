- **The browser app (factori.al) takes each factor's possible range.** Under the factors, "What each factor can be set
  to" holds a numeric factor's lowest and highest possible settings: a pressure that cannot go below zero. The path
  of steepest ascent stops before its first run past one, and the next study's ranges stay inside them. A design whose
  runs pass one, as a rotatable design's axial runs can, says which runs. A path that once listed no runs because a
  later run broke a limit on the settings now lists the runs before it. A study with a possible range is saved in
  study format 15, which an earlier page refuses.
