Run the experiments in the order listed, type each result into the response column, save, and drop the workbook here. A partly filled workbook is fine: the page analyses the completed runs.

How this works: Pyodide runs CPython compiled to WebAssembly. The page loads it from a public CDN, installs process-improve into it, and runs the same generate_design and analyze_experiment you would call in Python. The workbook is the only state; nothing is uploaded.
